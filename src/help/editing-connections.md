# Connections

Use connections and labels to add structure by connecting related ideas together.

## Set New Connection Colors

By default, new connection lines that you make use the same color as the last one. If you want each new connection to have a random color you can set that in `Settings → Connections → Use Last Color`

## Toggle Labels

To add explicit meaning to connection lines or colors, click on a connection and type in a label name. You explicitly toggle it with the `Label` button. You can also drag to reposition the label within the confines of the connection line.
